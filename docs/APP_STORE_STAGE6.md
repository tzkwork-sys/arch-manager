# Arch Manager — App Store Stage 6

Дата: **01.10.2026**

## Что доведено на этапе 6

Магазин приложений переведён в состояние повседневного использования и финализирован как нативная часть Arch Manager.

### Производительность и cache

- Каталог продолжает строиться в фоне и не блокирует GUI.
- Локальный JSON cache остаётся атомарным и versioned.
- Добавлен дополнительный **in-process memory cache** каталога: повторное открытие магазина в текущем сеансе не вынуждает заново читать JSON cache с диска.
- Cache каталога автоматически инвалидируется по fingerprint AppStream/pacman metadata.

### Media cache / offline mode

- Скриншоты продолжают загружаться лениво только после открытия карточки приложения.
- Media cache теперь имеет:
  - ограничение памяти;
  - ограничение размера на диске;
  - LRU-подобное вытеснение по последнему использованию;
  - atomic write;
  - безопасное поведение при read-only/повреждённом cache.
- При ручном или автоматическом retry stale/corrupted screenshot-cache может быть пересоздан.
- Без сети пользователь по-прежнему видит локальный каталог, установленные приложения, иконки и уже закешированные скриншоты; незакешированные показывают понятное сообщение о недоступности источника.

### Внешний вид и UX

- Кнопка обновления каталога показывает явное busy-состояние «Обновляю…».
- При отсутствии AppStream metadata страница объясняет причину и явно указывает безопасный штатный способ установить `archlinux-appstream-data`.
- Галерея скриншотов умеет автоматически пробовать повторную загрузку после обнаружения битого cache-файла.

### Надёжность и безопасность

- Магазин по-прежнему не выполняет partial upgrades и не управляет pacman напрямую из GUI.
- Полная системная установка обновлений остаётся на штатной странице «Обновления».
- При install/remove состояния магазина, Update State и остальных страниц синхронизируются без перезапуска.

## Тестовый контур

Добавлены regression-тесты на:

- in-process memory cache каталога;
- bounded/LRU media cache;
- retry-ремонт stale media cache;
- финальные release-инварианты страницы магазина.

Этап 6 завершает первую полную версию магазина официальных приложений Arch Linux внутри Arch Manager.
