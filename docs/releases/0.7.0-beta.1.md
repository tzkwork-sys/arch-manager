# Arch Manager 0.7.0-beta.1

Первый предварительный выпуск графического Arch Manager для Arch Linux x86_64.

> **Бета-версия, не стабильный релиз.** Установка на чистой Arch-системе,
> реальные пакетные операции и восстановление на отдельной тестовой системе
> для этого кандидата не проверены. Эти испытания отложены.

## Возможности

- Единый раздел официальных и AUR-обновлений.
- Каталог приложений, установленные приложения и системные пакеты.
- Точки Snapper, обслуживание и диагностика системы.
- Экспериментальная локальная/USB Recovery-среда.
- Обновлённая навигация и сокращение избыточных запросов sudo.

## Установка

Доступен готовый пакет **`arch-manager-0.7.0beta1-1-any.pkg.tar.zst`**.
Скачайте его и `SHA256SUMS.txt`, затем в папке загрузки выполните:

```bash
sha256sum --check --ignore-missing SHA256SUMS.txt
sudo pacman -Syu
sudo pacman -U ./arch-manager-0.7.0beta1-1-any.pkg.tar.zst
arch-manager-gui --check
```

Откройте **Arch Manager** из меню приложений, **не от root**. Зависимости и
обычные системные helpers устанавливает pacman. Нужны графический агент Polkit
и авторизация администратора. Recovery не входит в базовый пакет и не включается
при установке. Для AUR нужен отдельно установленный `yay`, для Snapper — уже
настроенная конфигурация `root` и дополнительные зависимости.

Для сборки приложен **`arch-manager-0.7.0beta1-1-build.tar.gz`** с `PKGBUILD`,
`.SRCINFO` и локальными файлами рецепта. Публикация в AUR пока не выполнена.
[Полная инструкция пакета, сборки и перехода с исходников](https://github.com/tzkwork-sys/arch-manager/blob/main/packaging/arch/README.md).

Исходный архив `arch-manager-0.7.0-beta.1-source.tar.gz` сохранён без изменений.
Альтернативная пользовательская установка — `bash scripts/install.sh` по
`docs/INSTALL.md`; не запускайте её и старые helper-установщики поверх пакета.

Пакет собран и проверяется автоматическими тестами и изолированным Qt smoke-test.
Это **не** проверка реальных пакетных операций или установки на чистой Arch VM.

## Ограничения и риски

- Основное окружение разработки — KDE Plasma. AUR требует `yay`.
- Локальный Recovery рассчитан на Btrfs `@` / `@snapshots`, systemd-boot с ESP
  в `/boot` и `/data/Arch-Recovery` на другом блочном устройстве от корня.
- Поддержка GRUB, ext4, шифрованных схем и Secure Boot не заявляется.
- **Создание USB Recovery стирает выбранный накопитель.**
- **Храните независимую резервную копию. Не полагайтесь на экспериментальный
  Recovery как на единственный способ восстановления рабочей системы.**
- Автоматические тесты не заменяют реальные испытания установки и отката.
