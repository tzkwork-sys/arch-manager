# Arch Manager — App Store Stage 4

Дата реализации: 30 сентября 2026.

## Реализовано

- GUI не получает root; пакетные изменения идут по цепочке `GUI → PackageActionService → pkexec → manage-applications → pacman`.
- Helper принимает только `install <package>` и `remove <package>` и повторно валидирует имя пакета.
- Установка разрешена только для пакета, существующего в официальных `core`, `extra` или `multilib`; helper сам формирует `repo/package`.
- `pacman -Sy <package>` не используется. Если текущая sync-база уже показывает ожидающие обновления системы, установка блокируется и GUI предлагает перейти на существующую страницу «Обновления».
- Перед изменением системы pacman в `--print` режиме строит план зависимостей. При установке подтверждение показывается, если затрагиваются дополнительные пакеты; при удалении всегда показывается состав удаления.
- Удаление использует `pacman -Rs` без `--nodeps`, `-Rdd`, `--cascade` и без автоматического удаления пользовательских файлов из `$HOME`.
- Одновременно разрешена только одна операция магазина; дополнительно учитывается штатный lock pacman.
- Ошибки Polkit, lock, места, подписи, сети/зеркала и конфликтов переводятся в понятные состояния, технические детали доступны в диалоге.
- После успеха состояние карточки обновляется; после закрытия карточки каталог перечитывается без cache.
- Запуск выполняется без root через системный desktop entry (`gio launch`) с безопасным fallback на проверенный `/usr/bin/<binary>`, без shell.

## Установка системного helper

Из корня проекта:

```bash
./scripts/install-app-store-helper.sh
```

Для отката только системного helper:

```bash
./scripts/uninstall-app-store-helper.sh
```
