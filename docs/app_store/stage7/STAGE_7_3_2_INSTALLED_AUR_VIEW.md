# Arch Manager — App Store Stage 7.3.2: Installed AUR view & update-policy hint

**Статус:** реализовано как UX/read-only дополнение после Stage 7.3.1.

## Что изменено

- Режим **«Установленные»** больше не является official-only.
- Фильтр источника в этом режиме остаётся доступным:
  - `Все` — установленные официальные desktop-приложения + подтверждённые AUR-пакеты;
  - `Официальные` — только AppStream/pacman-приложения;
  - `AUR` — только установленные пакеты, которые `AurService.installed()` подтвердил через aurweb.
- Список AUR загружается асинхронно через существующий `AurService.installed_async()`; GUI не выполняет `pacman`/`yay` напрямую.
- `pacman -Qm` не трактуется как готовый список AUR: неизвестные foreign-пакеты не показываются как AUR.
- Поиск внутри установленного AUR-списка локальный и не запускает AUR RPC search.
- Для `Все`/`AUR` категории отключаются, потому что AUR RPC не предоставляет совместимую AppStream-категоризацию. Для `Официальные` категории остаются доступны.
- Режим **«Обновления»** намеренно остаётся official-only до Stage 7.5.
- В режиме обновлений добавлено пояснение: официальные приложения обновляются вместе с полным системным обновлением Arch Linux, поэтому отдельной кнопки обновления в их карточках нет.

## Границы этапа

Stage 7.3.2 не добавляет удаление AUR (Stage 7.4) и не добавляет AUR update workflow (Stage 7.5).
