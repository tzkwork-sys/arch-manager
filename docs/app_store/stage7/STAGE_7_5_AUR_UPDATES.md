# Stage 7.5 — AUR updates

**Статус:** реализовано.

## Что добавлено

- режим «Обновления» магазина теперь объединяет официальные desktop-обновления и подтверждённые AUR-обновления;
- фильтр источника работает и для «Обновлений»: `Все / Официальные / AUR`;
- установленный AUR-пакет с новой версией получает действие «Обновить через yay»;
- удаление для такого пакета остаётся доступно отдельной кнопкой;
- массовое действие «Обновить все AUR» запускается отдельно от полного системного обновления и использует `yay -Sua`;
- AUR-обновление блокируется, если `pacman -Qu` показывает ожидающие официальные обновления;
- после терминальной операции локальное состояние пакета перечитывается, общий update-state инвалидируется, а список AUR обновляется;
- после полного системного обновления магазин принудительно перепроверяет AUR-состояние;
- все AUR-мутации по-прежнему выполняются от обычного пользователя в интерактивном терминале, без `--noconfirm` и без shell-eval.

## Безопасность и изоляция

Официальный helper/pacman-контур магазина не менялся. AUR использует отдельные planner/terminal runner и общий in-process package transaction coordinator. Кнопка «Обновить все AUR» не заменяет и не смешивается с полным обновлением Arch Linux.

## Команды

- один пакет: `yay -S --aur -- <package>`;
- все AUR: `yay -Sua`.

Перед запуском planner проверяет runtime/build prerequisites, pacman lock и отсутствие ожидающего официального system upgrade.
