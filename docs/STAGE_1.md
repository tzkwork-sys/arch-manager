# Этап 1 — каркас GUI

Реализовано:

- приложение на Python + PySide6 / Qt Widgets;
- главное окно Arch Manager;
- левая навигация по 8 разделам;
- стартовая страница «Обзор» с безопасными заглушками;
- страницы «Обновления», «Точки восстановления», «Обслуживание», «Восстановление», «Система», «Журнал», «Настройки»;
- нативное использование системной темы Qt/KDE (Breeze не переопределяется собственной цветовой схемой);
- автоматическое сохранение размера, положения окна и последней открытой страницы через `QSettings`;
- глобальная обработка непредвиденных ошибок и журнал в `~/.local/state/arch-manager/arch-manager.log`;
- SVG-иконка и отдельная `.desktop`-запись новой GUI-версии;
- установочный скрипт, который не заменяет ярлык старой консольной версии;
- legacy v1.8.4 оставлена без изменений.

## Доработка интерфейса 0.1.1

После визуальной проверки интерфейса:

- убрана служебная надпись «Этап 1 · каркас GUI» из боковой панели;
- скрыта неработающая кнопка «Проверить сейчас» до подключения реальной проверки;
- карточки на странице «Обзор» сделаны заметнее средствами системной Qt/KDE-палитры;
- временные статусы унифицированы как «Ещё не проверено»;
- пустые разделы получили один спокойный информационный блок вместо большого пустого пространства;
- настройка создания точки восстановления помечена как рекомендуемая;
- новая GUI-версия имеет отдельное имя ярлыка: «Arch Manager — новая версия».

## Запуск без установки

```bash
./scripts/run-gui.sh
```

Если PySide6 ещё не установлен на Arch Linux:

```bash
sudo pacman -S --needed pyside6
```

## Установка ярлыка в KDE

```bash
./scripts/install-stage1.sh
```

Скрипт создаёт пользовательский launcher `~/.local/bin/arch-manager-gui`, устанавливает иконку, запись «Arch Manager — новая версия» в меню KDE и отдельный ярлык новой версии на рабочем столе. Старый ярлык `Arch Manager` не изменяется.

## Ограничение этапа 1

GUI намеренно не вызывает `sudo`, `pkexec`, `pacman`, `yay`, Btrfs/Snapper из своего интерфейса и не меняет систему. Подключение read-only данных запланировано на этап 2.
