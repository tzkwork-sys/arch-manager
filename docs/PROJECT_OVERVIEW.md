# Arch Manager — Руководство и обзор проекта

## 1. Концепция и назначение
**Arch Manager** — модульное десктопное приложение на Python (PyQt6) для автоматизации развёртывания, комплексной настройки, обслуживания и мониторинга операционной системы Arch Linux. 

Приложение объединяет высокоуровневый графический интерфейс с проверенными системными Bash-скриптами и системными утилитами (`pacman`, `systemctl`, `btrfs-progs`, `reflector` и др.), обеспечивая безопасность системных транзакций и прозрачный контроль над окружением.

---

## 2. Ключевые принципы разработки (AI Guidelines)
* **Язык проекта:** Интерфейс (UI), диалоги, всплывающие уведомления, техническая документация и комментарии к коду ведутся строго на **русском языке**.
* **Двойная синхронная актуализация:** При любом изменении функционала, кодовой базы или структуры файлов в ответе ВСЕГДА предоставляется Bash-скрипт, который точечно модифицирует исходный код и синхронно обновляет актуальные файлы в каталоге `docs/`.
* **Монолитные обновления:** Доставка изменений осуществляется готовыми Bash-скриптами через синтаксис `cat << 'EOF'` с финальной валидацией синтаксиса через `python3 -m py_compile`.
* **Архитектурный контроль:** Запрещено создание файлов-свалок. Лимит размера файла — 250–300 строк. При превышении модуль разбивается на логические подмодули.

## 3. Стандарты UI / UX
* **Геометрия окна:**
  * Главное окно имеет фиксированный или строго ограниченный размер (без произвольного растягивания сетки элементов).
  * Центрирование окна на экране при запуске выполняется вызовом метода `center_on_screen()`.
  * В правом верхнем углу окна обязательно размещается ненавязчивая метка версии мелким шрифтом цвета `#6c7086`: `v.1.0`.
* **Стиль и цветовая палитра:**
  * Тёмная тема на основе палитр **Catppuccin Mocha** и **Breeze Dark**.
  * Оформление полей ввода строго вертикальное: заголовок размещается над полем (`QLabel.fieldLabel`). Избыточные карточки-контейнеры исключены.
* **Шкала прогресса (ProgressBar) и логирование:**
  * Индикатор операций отображает реальные фазы выполнения системных скриптов (монотонное движение без зависаний).
  * При смене вкладки, переключении режима или изменении параметров шкала сбрасывается в 0%.
  * Построчный консольный вывод системных утилит транслируется в раскрываемый блок «Лог ▼».
* **Превентивные проверки:**
  * Перед вызовом привилегированных команд или специфических утилит производится проверка окружения (`shutil.which()`, проверка статуса `polkit`/`sudo`).
  * При отсутствии пакета выводится модальное окно с описанием зависимости, готовой командой `pacman -S <pkg>` и кнопкой копирования в буфер обмена.

## 4. Спецификация релизной упаковки для Arch Linux
* **Именование:** Предотвращение коллизий в AUR и локальной базе `pacman` реализуется префиксом автора (например, `tzenzik-arch-manager`). В меню приложений KDE Plasma отображается человекочитаемое имя: **Arch Manager**.
* **Артефакты сборки:**
  * `PKGBUILD` — нативный сценарий сборки Arch-пакета (`.pkg.tar.zst`).
  * `arch-manager.desktop` — интеграция с меню окружения рабочего стола (KDE Plasma, GNOME, XFCE).
  * `arch-manager.sh` — стартер запуска в `/usr/bin/` с предварительной проверкой зависимостей окружения Python.
