# Сообщения об уязвимостях

Arch Manager выполняет чувствительные системные операции. Предварительная
версия 0.7.0-beta.1 ещё проходит подготовку и не имеет гарантированного срока
исправлений. Стабильный выпуск пока не объявлен.

**Не публикуйте эксплуатационные подробности, ключи, пароли или токены в Issue.**

Если на странице Security репозитория доступна кнопка **Report a vulnerability**,
используйте приватное сообщение GitHub. Эта возможность должна быть включена
владельцем отдельно; наличие этого файла её не включает.

Если приватный канал недоступен, откройте Issue только с просьбой предоставить
канал конфиденциальной связи, без описания способа эксплуатации. До получения
такого канала не отправляйте чувствительные материалы.

В приватном сообщении укажите версию/коммит, затронутый компонент, влияние,
безопасные шаги воспроизведения и предлагаемое исправление. Не испытывайте
уязвимость на чужих системах или рабочих дисках.
