Arch Manager v1.8.4

Исправления после полного теста локального восстановления без USB:

1. mkinitcpio теперь запускается только из настоящего смонтированного восстановленного @ через arch-chroot.
   Это устраняет предупреждение "root is not a mountpoint" и ошибку autodetect root filesystem.
2. Русские описания Snapper в info.xml декодируются из числовых XML entities (&#x....; / &#....;).
3. После восстановления создаётся last-restore.env в отдельном @snapshots.
4. В меню восстановления появился пункт "Последнее восстановление / старый @.broken".
   Он показывает состояние последнего восстановления и предлагает удалить старый корень только после безопасных проверок.
5. Для восстановления, выполненного версиями 1.8.0–1.8.3, статус умеет читать старый restore-*.txt, поэтому текущий @.broken тоже можно проверить из v1.8.4.
6. Старый @.broken никогда не удаляется автоматически.
7. Recovery ISO будет автоматически пересобран из-за смены версии на 1.8.4.
