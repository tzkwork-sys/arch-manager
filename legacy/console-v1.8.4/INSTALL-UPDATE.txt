Arch Manager v1.8.4 — обновление локального восстановления

1. Скачайте Arch_Manager_v1.8.4_Update.sh.
2. Запустите:
   bash "/data/UserFolders/Загрузки/Arch_Manager_v1.8.4_Update.sh"
3. Обновлятор сделает резервную копию проекта и запустит install.sh.
4. При следующем локальном восстановлении Recovery ISO пересоберётся автоматически.

После установки откройте:
Снапшоты Btrfs / Snapper → Восстановление системы → Последнее восстановление / старый @.broken

Для уже выполненного восстановления v1.8.3 Arch Manager прочитает старый restore-*.txt и сможет проверить @.broken-20260920-230223.
